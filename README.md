# AutoMate — First Website Build

Premium dark, responsive automotive discovery website starter for India + global car research.

## Included
- Car directory with search and filters (market, body type, powertrain)
- Car detail popups
- Compare up to 3 cars
- EMI and fuel-cost calculators
- Buying guide section
- Mobile responsive layout
- Static Netlify-ready files

## Files
- index.html — page structure and SEO metadata
- styles.css — design and responsive styling
- cars.js — starter sample car data
- app.js — search, filters, comparison and calculator logic

## Deploy
Connect this GitHub repository to Netlify and use the repository root as the publish directory. No build command is required.

## Important data note
The catalogue is demo/starter data, not a live database. Price ranges may be outdated and global prices are market-dependent. Verify current model year, variant, prices, taxes, safety ratings, specifications and availability with manufacturers or authorised dealers before publishing as factual buying guidance.

Before public launch, add verified model/variant data and sources, About, Contact, Privacy Policy, Terms, Disclaimer, editorial methodology, a real contact email, analytics and advertising policy setup.
